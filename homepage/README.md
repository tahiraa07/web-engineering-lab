# Tahira | Homepage

A responsive, dark and minimal personal homepage built with React and Vite.

**Live site:** https://YOUR-SITE.vercel.app  <!-- replace with your real URL -->

## Features
- Semantic HTML: header, nav, main, sections, footer
- Sections: hero, about, projects, skills, contact
- Mobile-first responsive layout
- Alt text on every image, skip link, visible keyboard focus

## Run locally
```bash
npm install
npm run dev
```

## Deploy
Connected to Vercel from GitHub. Every push to `main` deploys to production automatically.
